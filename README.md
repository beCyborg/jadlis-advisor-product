# Идею проверяешь той книгой, которую дочитал последней, — и она всегда соглашается

Шестнадцать линз читают каждая свою книгу и отвечают порознь, не видя ответов друг друга, а
совпавшее и спорное разбирают скептики: в раздел «Что делать» уезжает только то, что устояло.

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install advisor-product@jadlis
```

Ключей и подписок на сторонние сервисы плагин не просит — нужна только папка памяти: без неё
совет останавливается на первом шаге и ничего не пишет.

![Шестнадцать линз отвечают порознь, скептики бьют по совпавшему, валидатор пишет один вердикт](docs/img/hero-jadlis-advisor-product.webp)

Текстом: слева твой вопрос, в середине шестнадцать изолированных линз-книг, справа слой скептиков,
а на выходе один файл вердикта в твоей папке памяти.

Это моё рабочее место, выложенное как есть, а не продукт: чем перестал пользоваться — убрал.

## Было → стало

| Руками | Чатом с ИИ | Этим плагином |
|---|---|---|
| **Чем проверяется идея.** Под рукой одна-две книги, и обе написаны про чужой случай. | Отвечает из общего перемешанного знания: какая книга что сказала, разделить нельзя. | Каждая линза читает только свой конспект и отвечает тегами из него; знание других книг в её ответ не попадает. |
| **Откуда берётся согласие.** Мнения собираются по очереди, и первое задаёт рамку остальным. | Одна рамка на весь ответ — сравнивать не с чем. | Линзы работают параллельно и не видят ответов друг друга; куратор собирает совпадения и противоречия в проверяемые утверждения. |
| **Что делают с совпавшим.** Сошлось у нескольких книг — считается доказанным. | Совпадение внутри одного ответа не проверяется вовсе. | По каждому утверждению идут три скептика с заданием опровергнуть; большинство «опровергнуто» выбрасывает его из «Что делать». |
| **Возраст советов.** Тактика из старой книги применяется как сегодняшняя. | Год издания в ответе не виден. | У линз-ветеранов в реестре стоит роль-флаг: принципы живы, конкретика инструментов и каналов помечена мёртвой, и валидатор это учитывает при взвешивании. |
| **Что остаётся после разбора.** Решение и его причина остаются в голове. | Остаётся лента переписки, в которой ничего не найти. | Вердикт ложится файлом в твою папку памяти, строка — в журнал советов, контекст сессии — в профиль совета. |

## Как это работает

![Интервью, шестнадцать линз параллельно, гейт кворума, скептики по утверждениям, валидатор и файл вердикта](docs/img/how-jadlis-advisor-product.webp)

На входе — твой вопрос и профиль из папки памяти.
Внутри — линзы сдают уточняющие вопросы, ты отвечаешь один раз на всех; дальше фан-аут,
гейт кворума, слой скептиков по каждому утверждению и один валидатор.
На выходе — файл вердикта со SWOT, картой консенсуса и колонкой леджера.

Текстом: вопрос → уточняющие вопросы линз одним списком → шестнадцать ответов порознь → кворум →
скептики по утверждениям → валидатор → файл вердикта в папке памяти.

Держится вердикт на ограничениях, зашитых в код. Линза отвечает только от лица своей книги
и обязана поставить citation-тег, существующий в её конспекте, — выдуманный тег обнуляет
рекомендацию. Вердикт выпускается, только если ответило минимум одиннадцать линз из шестнадцати;
меньше — совет отдаёт сырые ответы с предупреждением и синтеза не делает. Куратор отбирает самые
решающие утверждения, и по каждому голосуют три независимых скептика: опровергнутое не попадает
в «Что делать», спорное уходит в «Против» и помечается в карте консенсуса. Валидатор — единственный,
кто синтезирует: он взвешивает линзы по релевантности, конкретности, согласию и их собственной
уверенности, раскладывает рекомендации по восьми продуктовым категориям и отдельной секцией
выписывает слепые зоны — то, чего ты не знал и о чём тебя не успели спросить.

Иногда после проверки не остаётся ничего. Это ответ «оснований под решение нет», а не поломка:
единогласие ростера чаще означает общую школу или общую формулировку задачи, чем независимое
подтверждение.

## Установка и первый запуск

**а) Текст для вставки агенту.** Скопируй целиком в чат Claude Code:

```
Ты — установщик. Поставь на этот Mac плагин advisor-product из маркетплейса jadlis.
Выполни ровно эти команды, дословно, ничего не сокращая:
1. claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
2. claude plugin install advisor-product@jadlis --config MEMORY_DIR=~/advisors-memory
3. claude plugin list — покажи мне строку про advisor-product и его версию.
MEMORY_DIR — обычная папка на диске, куда совет пишет вердикты, журналы и профили;
спроси меня, какую папку взять, и подставь мой ответ вместо ~/advisors-memory.
Перед каждой командой покажи её мне целиком и дождись «да». Сказал «нет» — не выполняй,
скажи, что именно пропустил, и иди дальше.
Команда вернула ошибку — остановись, покажи вывод, к следующей не переходи.
```

**б) Команды руками.**

```
claude plugin marketplace add https://github.com/beCyborg/jadlis-start.git
claude plugin install advisor-product@jadlis --config MEMORY_DIR=~/advisors-memory
claude plugin list
```

Первая команда ничего не ставит — она добавляет маркетплейс. Ставит только вторая, и снимается
она одной строкой: `claude plugin uninstall advisor-product@jadlis --keep-data`.

`MEMORY_DIR` — единственная настройка плагина: папка, за пределы которой совет не пишет ничего.
Все советы Jadlis могут смотреть в одну и ту же. Скелет папки разворачивается сам при первом
запуске и существующие файлы не трогает. Поменять путь потом можно только переустановкой: на уже
установленном плагине флаг `--config` молча ничего не меняет (проверено 07.09.2026).

**в) Короткая команда.** Открой Claude Code в папке, где работаешь, и набери:

```
/advisor-product <вопрос по продукту>
```

Не находится — сверь имя строкой `claude plugin list`. Первым делом совет соберёт уточняющие
вопросы линз и задаст их тебе одним списком: ответы уходят всем шестнадцати сразу, а то, что
осталось неизвестным, попадёт в вердикт секцией «Слепые зоны».

## Границы, стоимость, обновление

**Чего не делает.** Не ходит в интернет и не сверяется с рынком: линзы отвечают из конспектов книг,
доступа к свежим данным у них нет. Не заменяет юриста, бухгалтера, финансового советника и врача —
это не профессиональная консультация. Не выдаёт библиографию: тег вида `[MT:R1]` указывает на блок
конспекта внутри плагина, а не на страницу книги. Не принимает решение за тебя и не несёт за него
последствий — вердикт это остаток после внутренней проверки, а не подтверждённый факт о мире.
Не пишет никуда, кроме папки памяти. И не правится здесь: репозиторий генерируется из приватного
источника, прямые правки CI отклоняет — заметил ошибку, заводи issue, она приедет следующим релизом.

**Что нужно.** Ключи не нужны, подписки на сторонние сервисы тоже: совет работает внутри Claude Code
на твоей квоте. Нужна папка для памяти советов — задаётся при установке ключом `MEMORY_DIR`.
Содержимое папки приватное: там лежат твой профиль, журналы и вердикты, поэтому выбирай место
с оглядкой на синхронизацию и бэкапы.

[уточнить] — минимальная версия Claude Code с инструментом Workflow в репозитории не зафиксирована.

**Порядок расхода токенов.** Прогон тяжёлый: десятки субагентов из твоей квоты — шестнадцать линз
на уточняющие вопросы, шестнадцать на разбор, куратор, по три скептика на каждое проверяемое
утверждение и валидатор. Исчерпанное сессионное окно валит фан-аут целиком, а не частично: линзы
возвращают отказ, кворум не набирается, вердикта нет. Поэтому смотри остаток окна до старта, а не
после; несколько советов подряд в одно окно не помещаются. Это инструмент для вопросов, которые
не переигрываются.

**Проверено там, где я работаю:** мой Mac, моя подписка. Где ещё это работает — [уточнить].

**Условия использования.** Лицензии нет: все права сохранены за автором. Читать и
пользоваться лично можно. Коммерческое использование, переиздание и включение в свои
продукты — по договорённости со мной.

Конспекты книг — производные работы, и границы у них отдельные: они разобраны в `NOTICE.md`.

**Обновление.** У стороннего маркетплейса авто-обновление на твоей стороне выключено: пока не
запустишь первую команду, у тебя остаётся та версия, которую ты поставил.

```
claude plugin marketplace update jadlis
claude plugin update advisor-product@jadlis
claude plugin list
```

Переустановка, если что-то встало криво:

```
claude plugin uninstall advisor-product@jadlis --keep-data && claude plugin install advisor-product@jadlis
```
