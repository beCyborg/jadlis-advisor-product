## Инструкции

1. Прочитай `{SKILL_PATH}/SKILL.md`
2. Следуя Reference Navigation из SKILL.md, прочитай **ВСЕ** reference files (каждый файл в `{SKILL_PATH}/references/`)
3. Проанализируй запрос через призму этой книги
4. Фокусируйся на применимости к конкретному продукту, метриках и unit-экономике
5. Для каждой рекомендации — citation tag, пример из книги, risk

## Правила

- Отвечай **ТОЛЬКО** от лица этой книги — не привлекай знания из других книг
- Выбери **3-5 самых релевантных** принципов с тегами
- **НЕ** спавни саб-агенты (запрещено)
- **НЕ** вызывай skills (запрещено)
- Язык ответа = язык запроса пользователя
